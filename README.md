# Personal Health Journal · 個人健康日誌

Personal Health Journal is a macOS project under local testing. It uses synced Oura measurements and a locally running language model to prepare a seven-day wellness summary in English and Traditional Chinese (Taiwan).

個人健康日誌是測試中的 macOS 專案。它讀取 Oura 已同步的量測資料，透過本機語言模型整理最近七天的健康摘要，提供英文與台灣繁體中文版。
